# Olá, eu sou o Ruan Carlos! 👋
### Engenheiro de Dados | Data Warehouse • ETL • BI

Trabalho com Engenharia de Dados, projetando e implementando Data Warehouses dimensionais (Kimball), pipelines de ETL e APIs de ingestão em ambiente produtivo. Antes disso, atuei como desenvolvedor Full Stack (Java, Groovy, Angular), vivência que hoje me ajuda a construir soluções de dados mais integradas ao produto.

---

### 🚀 Sobre mim

* 🎓 Graduando em **Sistemas de Informação** pela **UFG** (2023 – 2027).
* 🏗️ Projetei e implementei do zero um **Data Warehouse dimensional (Kimball)** em PostgreSQL 16, com **SCD Tipo 2** e auto-referências recursivas.
* 🔄 Construo **pipelines de ETL no n8n** com cargas incrementais, enriquecimento idempotente (COALESCE) e resolução de chaves via lookup.
* ⚡ **Otimização:** migração de paginação offset para keyset em cargas de milhões de registros, eliminando perda de dados.
* 🔐 **Back-end:** API intermediária em **FastAPI** para expor o DW ao orquestrador com autenticação dupla (Cloudflare Access + API key) e whitelist de tabelas/colunas.
* 📊 **BI:** modelagem de KPIs no **Apache Superset** para consumo pelo time de negócio.
